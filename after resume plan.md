1. Public Candidate Skill Test Flow

This starts from the Resume page.

Candidate comes to your website
        ↓
Uploads resume
        ↓
AI extracts skills
        ↓
System generates or selects test based on resume skills
        ↓
Candidate gives test
        ↓
Candidate gets verified skill result
        ↓
Companies can see candidate result
        ↓
Company contacts or hires candidate

Step 2: Candidate Confirms Skills

Do not directly generate test from AI-extracted skills.

First show the extracted skills to the candidate.

Example:

We found these skills in your resume:

Frontend:
- HTML
- CSS
- JavaScript
- React

Backend:
- Node.js
- Express.js

Database:
- MongoDB
- MySQL

Tools:
- Git
- Firebase

Candidate actions:

Confirm skill
Remove wrong skill
Add missing skill
Set skill level

Example:

React — Intermediate
Node.js — Beginner
MongoDB — Intermediate
JavaScript — Intermediate

This confirmed skill list becomes the base for the test.

Important Suggestion: Do Not Generate Fully Random Questions Every Time

For public candidate results, companies need to compare candidates fairly.

If every candidate gets completely different AI-generated questions, then this becomes difficult:

Candidate A score: 85%
Candidate B score: 85%

But both may have answered different difficulty questions.

So use this better method:

Resume skills extracted
        ↓
System selects test topics
        ↓
Questions come from approved question bank
        ↓
AI can help generate draft questions
        ↓
Admin/reviewer approves questions
        ↓
Candidate gets standardized skill test

Use AI for:

Skill extraction
Test recommendation
Question draft generation
Explanation generation
Result summary

But for public verified scores, use mostly approved question bank questions.

Step 3: Generate Skill-Based Test Plan

After candidate confirms skills, system creates a test plan.

Example candidate skills:

React
JavaScript
Node.js
MongoDB
Git

System generates test structure:

Recommended Skill Test:

1. JavaScript MCQ — 20 questions
2. React MCQ — 15 questions
3. Logic and Debugging — 10 questions
4. Coding Test — 2 problems
5. Database Basics — 10 questions

Total duration: 75 minutes

Candidate can see:

This test will verify your skills in:
- JavaScript
- React
- Node.js
- MongoDB
- Logic
- Coding
Step 4: Candidate Chooses Test Type

You can give three options.

Option A: Quick Skill Test
Duration: 20–30 minutes
Basic MCQ only
Good for beginner verification
Option B: Standard Skill Test
Duration: 60–90 minutes
MCQ + logic/debugging + coding
Best for public verified profile
Option C: Advanced Skill Test
Duration: 120 minutes
Advanced coding + debugging + role-level questions
Best for strong candidates

For your first version, build Standard Skill Test.

Step 6: Test Result Generation

Needs Improvement:

- Node.js middleware
- Advanced React hooks
Step 7: Skill Badge System

Create badges.

Example:

JavaScript Verified — 82%
React Verified — 76%
Coding Verified — 74%
Frontend Developer Readiness — 78%

Badge levels:

Beginner: 40–59%
Intermediate: 60–79%
Advanced: 80–89%
Expert: 90%+

Do not give badge if score is too low.

Example:

MongoDB score: 38%
Badge not awarded

Step 10: Company Invites Candidate

If company likes a candidate:

Recruiter views candidate skill result
        ↓
Recruiter sends job invitation
        ↓
Candidate receives notification
        ↓
Candidate accepts or rejects
        ↓
Candidate may apply or attend interview

Recruiter actions:

Invite to Apply
Send Message
Shortlist to Talent Pool
Schedule Interview
Request Job-Specific Assessment
